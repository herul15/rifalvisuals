# Local fonts

Latin variable WOFF2 files served by Google Fonts, downloaded on 2026-11-13:

- Playfair Display, normal, weights 400–900.
- Plus Jakarta Sans, normal, weights 200–800.

Source stylesheet: https://fonts.googleapis.com/css2?family=Playfair+Display:wght@400..900&family=Plus+Jakarta+Sans:wght@200..800&display=swap

License sources: https://github.com/google/fonts/tree/main/ofl/playfairdisplay and https://github.com/google/fonts/tree/main/ofl/plusjakartasans . Each family's OFL license is included alongside the font.

Next.js loads these checked-in files with next/font/local. No font download occurs during build or page load.
